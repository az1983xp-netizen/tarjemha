# Tarjemha V3 — AI Translation Engine

هذه النسخة تربط دورة الترجمة بمحرك AI عند توفير `OPENAI_API_KEY`.
واجهة الموقع تستقبل PDF/DOCX/TXT، تستخرج النص، تقسمه إلى أجزاء، تترجمه، ثم تمرره على فحص جودة، وتنتج ملف DOCX.

## ما زال مطلوبًا للإطلاق التجاري
- حساب API ومفتاحه.
- دفع حقيقي بدل demo-pay.
- OCR للملفات الممسوحة والصور.
- تخزين سحابي وحذف تلقائي للملفات.
- PostgreSQL بدل SQLite.
- نظام حسابات العملاء.
- بريد تلقائي.
- حماية/حدود حجم الملفات ومراقبة التكلفة.
- سياسة خصوصية وشروط خدمة.
- نشر على استضافة.
